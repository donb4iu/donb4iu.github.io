    18. Invalid affinity failure¶

    A temporary empty-string affinity caused Helm to fail:

    UPGRADE FAILED: cannot patch "kubecost-network-costs" with kind DaemonSet

    The verbose patch showed a string for a field expected to deserialize into v1.Affinity.

    Accepted correction:

    affinity:
  nodeAffinity:
    requiredDuringSchedulingIgnoredDuringExecution:
      nodeSelectorTerms:
        - matchExpressions:
            - key: kubernetes.io/os
              operator: In
              values:
                - linux

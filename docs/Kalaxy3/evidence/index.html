#Preservation rule

A newer SAGE schema must not make historical evidence undiscoverable, unpublished, or invalid merely because it predates the schema. Historical records remain preserved, classified, indexed, and assigned explicit metadata provenance. Migration is deliberate, reviewable, and non-destructive.
